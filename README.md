# 🚀 Space Shooter (Arcade Version)

A 2D space shooter game built using Python and the Arcade library.

---

## 🎮 Gameplay

Control your spaceship, eliminate incoming enemies, and survive as long as possible while increasing your score.

---

## 🛠 Built With

- Python 3
- Arcade Library

---

## 🎯 Features

- WASD movement
- Mouse-based aiming
- Shooting system with cooldown
- Enemy spawn system
- Collision detection
- Score tracking
- Player lives system
- Game Over & Restart system

---

## 🧠 What I Learned

- Object-Oriented Programming
- Game loop mechanics
- Collision detection using math
- Event-driven programming
- Managing game states
